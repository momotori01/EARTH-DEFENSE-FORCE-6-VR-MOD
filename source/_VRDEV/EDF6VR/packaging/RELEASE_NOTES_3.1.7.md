# EDF6VR 3.1.7

## Fixes

- More is now recorded when the game closes unexpectedly and when someone takes a vehicle seat, to track down the online vehicle problems. Nothing changes in play.
- A search the mod runs at the start of each mission no longer touches memory it cannot read.

Now bundles **EDF6MultiSlot 1.6.7** (plays together with 1.6.6).

To install, use one of these. Your settings are kept.
- Press **Update now** in EDF6 VR setting.exe.
- Run `Update_EDF6VR.bat`.
- Extract the ZIP over your game folder.
