# EDF6VR 2.1.2

- **New: left-handed mode.** Rangers, Wing Divers and Air Raiders can hold and fire the gun with the left hand. The trigger, grip, buttons and sticks all change sides with it (move with the right stick, turn with the left). Fencers and vehicles stay right-handed.
  **How to switch it on:** after updating, start the game once. Then open `Mods/Plugins/EDF6VR.ini`: the setting is at the very top of the file. Change `LeftHanded=0` to `LeftHanded=1` and restart the game. `LeftHanded=0` goes back to right-handed (the default). To keep the sticks where they are, also set `LeftHandedSticks=0`.
- **Auto-update:** `Update_EDF6VR.bat` is now included. Run it and it updates EDF6VR (with the bundled EDF6MultiSlot) to the latest release here. If you run into a bug, try this first. When a newer version is out, the lower-left line of the menu says so.
- **Cockpits:** better-looking surfaces, with new materials and textures.
- **Fencer:** better controls, closer to the game on a monitor.
- **Fencer:** after a revive, your equipment no longer points the wrong way.
- **Online, known issue (being fixed):** rarely, with certain players in the room, the host cannot press OK to start a mission. If it happens, restart the game.

Bundles EDF6MultiSlot 1.5.12. To install this version, extract the ZIP over your game folder as before; from now on `Update_EDF6VR.bat` does it for you. Your settings are kept.
