# EDF6VR 3.2.1

## Fixes

- FPS improved by 10–20%. This is a trial feature: if a visual problem appears, turn off **Faster visibility checks** in VR setting (the Start menu in the game, or EDF6 VR setting.exe).

Still bundles **EDF6MultiSlot 1.6.9**.

To install, use one of these. Your settings are kept.
- Press **Update now** in EDF6 VR setting.exe.
- Run `Update_EDF6VR.bat`.
- Extract the ZIP over your game folder.
