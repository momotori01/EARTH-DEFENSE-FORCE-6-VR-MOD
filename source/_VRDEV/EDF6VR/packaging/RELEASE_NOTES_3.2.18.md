# EDF6VR 3.2.18

## Online

- When the game closes on its own without an error (for example on the way back to the lobby) and Windows records nothing, the last SHUTDOWN line of `EDF6MultiSlot.log` now names the part of the game that closed it and what called it. Nothing else changes. If it happens, please send the logs (EDF6 VR setting.exe, problem report).

Now bundles **EDF6MultiSlot 1.6.14** (plays together with 1.6.12 and 1.6.13). Eight-player rooms still need 1.6.13 or later for everyone.

To install, use one of these. Your settings are kept.
- Press **Update now** in EDF6 VR setting.exe.
- Run `Update_EDF6VR.bat`.
- Extract the ZIP over your game folder.
