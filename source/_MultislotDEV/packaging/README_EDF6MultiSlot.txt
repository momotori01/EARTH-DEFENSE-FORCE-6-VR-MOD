EDF6 MultiSlot {VERSION}

■ 今回の更新（1.6.9）：5人以上のとき、エアレイダーの功績ポイントを調整しました
・5人以上のオンラインでは敵の数が増えるうえ、エアレイダーは何人いても全員が同じだけ功績ポイントをもらえるので、
  エアレイダーを何人も出すと爆撃を続けて撃てすぎていました。
・この版から、5人以上のときは、エアレイダー1人がもらえる功績ポイントを次のように減らします。
    エアレイダーの人数  1人 100% ／ 2人 75% ／ 3人 50% ／ 4人 40% ／ 5人 30% ／ 6人 25% ／ 7〜8人 20%
  さらに、部屋の人数が4人を超えた1人ごとに5%減らします（5人 95% ／ 6人 90% ／ 7人 85% ／ 8人 80%）。
  例：6人の部屋でエアレイダーが2人なら、1人あたり 75% × 90% = 67.5%。
・チーム全体では、エアレイダーが2人以上いるとき、同じ部屋にエアレイダーが1人だけのときのおよそ1.5倍に収まります。
・乗り物の要請も同じポイントを使うので、乗り物を呼べる間隔も同じだけ長くなります。
・4人までの部屋とオフラインは今まで通りです。
・功績ポイントは各自のPCで貯まるので、古い版の人とも一緒に遊べます（古い版のエアレイダーだけは今まで通り貯まります）。
  全員この版にそろえると公平です。

■ 1.6.8：5人目以降が救急車（キャリバン）やグレイプに乗ると落ちる問題を直しました
・キャリバン、グレイプ、トラックの後部座席は、ゲーム本来では「1人目は1番、2人目は2番…」と、人ごとに決まっています。
  席は4人分しかないので、5人目以降が乗ろうとすると席の表の外に書き込んでしまい、ゲームが落ちたり、
  後部座席に座れなかったりしていました。
・この版から、5人目以降は空いている後部座席に座ります。1〜4人目の席の決まり方は今まで通りです。
・直るのは、乗ろうとする本人がこの版を入れているときです。5人以上で遊ぶときは全員この版にしてください
  （1.6.6 / 1.6.7 の人とも同じ部屋で遊べます）。
・乗り物に乗れる人数は今まで通りです（キャリバンは運転席と後部座席4つ）。

■ 1.6.7：落ちたときと、乗り物の座席の記録を増やしました（ゲームの動きは変わりません）
・ゲームが落ちたとき、どこで落ちたかを EDF6MultiSlot.log に必ず残すようにしました。
  これまでは、落ちた場所によっては何も残りませんでした。
・乗り物に乗り降りしたとき、誰がどの乗り物の何番の座席に座ったかを記録します。
  5人以上で乗り物に乗ると落ちる・乗れないことがあるので、その調査のためです。
・1.6.6 の人とも、今まで通り同じ部屋で遊べます。
・記録を止めるときは、ini の [MultiSlot] に NetLog=0 と書きます。

■ 1.6.6：VR の両手撃ちが、他の人にもその向きで見えるように受け取る側を直しました
・VR で両手に別々の向きで撃った弾が、他の人の画面でもそれぞれの向きに飛ぶよう、受け取る側を直しました
  （連射武器と、ハンドキャノンのように1発ずつ撃つ武器）。
・注意：この版と古い版は、同じ 8Player MOD の部屋に入れません
  （入ろうとすると「バージョンが違う」と表示されます）。5人以上で遊ぶときは、全員この版にそろえてください。
  4人までの普通の部屋は、今まで通り誰とでも遊べます。

■ 1.6.2：バージョンが違う部屋に入ろうとすると、そう表示されるように
・MultiSlot の部屋（8Player MOD の部屋）にバージョンの違う人が入ろうとすると、
  「MultiSlotのバージョンが違うため、ルームに参加できませんでした。」と表示し、
  部屋が古いのか新しいのか、どちらがアップデートすればよいかを伝えます（ゲームが日本語なら日本語、それ以外の言語なら英語）。
・ルーム一覧から入る場合も、招待から入る場合も同じです。
  これまでは、新しい版の人が一覧から古い版の部屋に入れてしまうことがありました。
  この版からは、一覧からでも入れずに上の表示が出ます。
・4人までの普通の部屋（8Player MOD OFF で作った部屋）は、バージョンが違っても、MOD なしの人とも、今まで通り遊べます。
・古い版（1.5.38 以前）の人には、この表示は出せません（古い版の一覧には新しい部屋がそもそも出ません）。

■ 1.5.38：VR で両手に持った武器を別々の方向に撃ったとき、他の人にもその通りに見えるように
・VR では、レンジャーは両手の銃を、フェンサーは左右の武器を、それぞれの手の向きに撃てます。
  ところが EDF6 は1人に照準を1つしか持たないので、他の人の画面では両方とも同じ方向に飛んでいました。
・この版から、EDF6VR が手の向きをこの MOD に渡し、この MOD が部屋の他の人に送ります
  （ゲーム自身の通信のすぐ後に数十バイト。EDF6VR が向きを変えている間だけ）。
  受け取った側では、その向きで相手の弾を撃ちます。
・見え方：
  - 見る人が MOD を入れていれば、VR でも VR なし（設定ツールの「Normal (no VR)」）でも2方向に見えます。
    連射武器の弾は、VR の有無に関係なくこの MOD が手の向きへ回します。
  - 見る人が MOD を入れていない場合、連射武器は1方向のままです。
    単発で撃つ武器（狙撃銃など）は、ゲーム自身の通信に向きが乗るので、2方向に見えることがあります。
・撃つ人には、対応した EDF6VR が必要です。それまでは何も送りません。
・MOD を入れていない人や古い版の人にも届きますが、ゲームはこの通信を読まずに捨てます（先頭が 0 の
  2バイトで始まる通信は、ゲームが読み飛ばす作りです）。部屋の参加や同期には影響しません。
・切るときは ini の [Sync] に HandAim=0 と書きます。

■ 1.5.35：人が入ってきて約20秒後に、何人もが一斉に部屋から落ちる問題の対策
・部屋に入ると、ゲームは全員と1人ずつ接続して参加の確認をします。確認が5秒で取れないと、
  ゲームはその接続を切って最初からやり直し、20秒たっても取れないと自分から部屋を出ます。
・中継経由で接続に4〜5秒かかる人がいると、つながった直後にこの「5秒でやり直し」で切られ、
  何度やり直しても同じことになっていました。20秒たつと、その人と確認が取れなかった全員が
  同時に部屋を出ます。人数が多いほど起きやすく、6〜8人の部屋で起きていました
  （記録に残っていたやり直し53回のうち30回が、つながったばかりの接続を切っていました）。
・対策：やり直すまでの時間を5秒から10秒にしました。20秒の期限やつなぎ直しの仕組みは
  ゲーム本来のままで、本当に切れた接続は今まで通りつなぎ直します（10秒後になるだけです）。
・接続はどちらの側からでも切られるので、全員が入れていると一番効果があります。
  MODを入れていない人と組んでも問題はありません（こちらが切らなくなるだけです）。
・ゲーム本来の5秒に戻すときは、ini の [MultiSlot] に JoinRetrySeconds=5 と書きます。

■ 1.5.34：ログの追加だけです（ゲームの動きは変わりません）
・8人で出撃すると全員が落ちる件の調査用に、出撃時の同期データの大きさをログに書くようにしました。
  出撃時はホストが全員の装備を1つにまとめて送りますが、EOS は1回に 1170 バイトまでしか送れず、
  ゲームはそれを超えたデータを黙って捨てます。装備1人分は 133〜217 バイトなので、8人だと
  中身によっては超えてしまう可能性があります。
  ホストでもゲストでも、5人以上で出撃したときのログがあれば、8人で超えるかどうかが分かります。

■ 1.5.32：オンラインで他の人の位置と向きがずれる問題を直しました
・他の人が実際と違う場所に見える（止まっているのに何メートルも離れたまま固まる、
  違う場所に着地してからスーッと滑って合う）、違う方向を向いて見える、という問題です。
・原因：EDF6 は自分の位置と向きを「6フレームに1回」だけパケットに入れる作りですが、
  パケットは約0.1秒ごとに最新の1個だけが送られます。60fps ではこの2つの周期がぴったり重なるため、
  位置や向きが「毎回届く」か「何秒も1個も届かない」かのどちらかに固定されていました
  （実測：他の人のパケットのうち位置が入っていたのは 1.3〜5.9%、向きは 6%）。
  以前「MOD では直せない」と書いていましたが、原因の読み違いでした。
・対策：自分のパケットに、毎回、位置と向きを入れて送ります（1パケットあたり十数バイト増えるだけです）。
・実測（2人、2026-09-30）：他の人の位置のずれ 中央値 1.57m → 0.26m、最大 17m → 4m、
  向きのずれ 117度 → 0度。
・直るのは「入れた人が、他の人からどう見えるか」です。全員が入れると、全員が正しく見えます。
  MODを入れていない人や古い版の人も、今まで通りに受け取れます（受け取る側の処理はゲーム本来のままです）。
・切るときは ini の [Sync] に PositionEveryPacket=0 / FacingEveryPacket=0 と書きます。
・部屋の仕組みや参加の判定は変えていません。1.5.5 以降の人とも互いに部屋が見え、参加できます。

■ 調査に協力してもらうときだけの設定（初期設定はオフ。普段は何もしません）

  1回だけ保存します。ダンプにはゲームのメモリの内容（部屋名や名前など）が入るので初期設定はオフです。

■ 導入
ZIPの中身を、EDF6のゲームフォルダ（EDF6.exe がある場所）にそのままドロップしてください。
ゲームを終了してから、winmm.dll も「置き換える」で更新してください（競合を修正したEDFModLoader本体です）。
あとはSteamからいつも通り起動するだけで有効になります。
ゲームフォルダは、Steamライブラリで EDF6 を右クリック → 管理 → ローカルファイルを閲覧 で開けます。

設定ファイルは同梱していません。初めて起動したときに Mods\Plugins\EDF6MultiSlot.ini が作られます。
ModLoader.ini も同梱していないので、ほかのMODのために変えている設定はそのまま残ります。
起動するとプラグインが Mods\UI\LYT_MAINFRAME.SGO（メニュー画面の枠に表示欄を1つ足したもの）を書き出します。
MODを無効にしたとき（Enabled=0）やゲームが更新されて対応外になったときは、自分で消してゲーム本来の表示に戻します。
ほかのMODが同じ名前のファイルを入れている場合は、そのファイルには触りません（左下の表示が出ないだけで、F2 は効きます）。

■ できること
・部屋の外のメニュー画面で F2、またはパッドの左スティック押し込みで 8Player MOD を切り替えます
  左下に「F2/LS 8Player MOD :OFF」「F2/LS 8Player MOD :ON」と出ます（部屋の中と出撃中は出ません）
  この設定で、自分が作る部屋の種類と、部屋検索に出る部屋が変わります
  - OFF（最初の設定）：作る部屋は、誰でも見つけて入れる、いつもの4人部屋です。MODを入れていない人とも遊べます
    部屋検索には、通常の部屋とMultiSlot部屋の両方が表示され、どちらにも参加できます
  - ON：作る部屋は、最大8人の MultiSlot 部屋です。このMODを入れていない人には表示されません
    部屋検索には、8人部屋（MultiSlot部屋）だけが表示されます。通常の4人部屋を探すときは OFF にしてください
  - 部屋検索の一覧を見ているときに切り替えると、その場で検索し直します
  - 部屋は作ったときの設定のままです。部屋の中で F2 を押しても切り替わりません
    （自分が作った部屋の中では、左下に「8Player MOD :ON」のようにその部屋の設定が出ます）
  - 切り替えは ini の [MultiSlot] EightPlayerRooms に保存されるので、次に起動したときもそのままです
・部屋画面の隊員欄は4人ずつ表示されます。5人以上いるときは、
  右スティック押し込み（キーボードは F3 か Tab）で 1〜4人目 と 5〜8人目 の表示を切り替えます
  操作説明として、部屋画面の左下に「F3/Tab/RS: Members 5-8」のように押すと出る隊員が表示されます
  （RS は右スティック押し込み。自分が作った MultiSlot 部屋では常に、ほかの部屋では5人以上いるときに出ます）
  （ボタンは ini の [RoomScreen] PageButton / PageKeys で変えられます。F2 は 8Player MOD 用なので使えません）

■ アーマーを合わせる（F4）
・部屋の中で F4、またはパッドの左スティック押し込みで ON/OFF。左下に「F4/LS copy armor :ON/OFF」と出ます
・ON の間、自分のアーマーが、同じ部屋にいる他の人の中で一番低い人の値まで上がります
  - 自分と同じ兵科の人がいれば、その中で一番低い人
  - いなければ、部屋全体で一番低い人
  - 上げるだけです。自分の方が高ければ何もしません
  - 自分との差が 300 以下の人は飛ばして、その上の人の値を取ります
    （初心者が複数いるとき、お互いを見て動かなくなるのを防ぐためです。
      例: 部屋が 3000 / 2000 / 300 / 200 なら、300 の人も 200 の人も 2000 をコピーします）
    この 300 は ini の [CopyArmor] IgnoreWithin で変えられます
  - 兵科ごとに上限があります（レンジャー 4000 / ウイングダイバー 2500 / エアレイダー 3000 / フェンサー 4000）
    上限を超える相手をコピーしようとしたときは上限で止まり、表示が「copy armor :2500(Max)」になります
    ini の [CopyArmor] MaxRanger などで変えられます（0 で上限なし）
・誰かが入ってきたり、自分や他の人が兵科を変えたりすると、そのたびに計算し直します
・EDFを始めたばかりの人が、体力面で足を引っ張らずに一緒に遊ぶための機能です
・セーブデータには一切書きません。OFF にすれば元通りで、部屋を出た時点でも解除されます
・部屋のメンバー欄には、自分にも他の人にも「本当のアーマー」が出ます。上がるのはミッションの中だけです
  （上げた値を部屋に出すと、それを他の人がコピー元にしてしまい、初心者が複数いる部屋で
    全員が上に引っ張られるためです）
  効いているかは、メニュー左下の「F4/LS copy armor :2000」の数字で確認してください
・ini の [CopyArmor] で キーやボタンを変えたり（Key= / PadButton=）、機能ごと入れないように（Enabled=0）できます
  F4 は EDF6VR の開発キーのひとつです。EDF6VR の ini で DevKeys=1 にしている場合は別のキーにしてください
・操作のまとめ（これまでの操作はそのままで、左スティックと F4 が増えただけです）:
    部屋の外   F2 / 左スティック押し込み   8Player MOD の ON/OFF（ON の間、部屋検索は8人部屋だけ）
    部屋の中   F3 / Tab / 右スティック押し込み   5人目以降のページ切り替え
    部屋の中   F4 / 左スティック押し込み   アーマーを合わせる ON/OFF
  その場でできる操作だけが画面の左下に出ます

■ ミッション（5〜8人）
・5〜8人目の装備、プレイヤーの作成、出現位置、「エリア到達」「全員集合」などの判定、
  拾ったアイテムの数に対応しています（4人以下のときはゲーム本来と同じ動きです）
・5〜8人のオンラインミッションの難易度（全員同じ計算になるよう固定です）
  - 敵の数：5人 1.2倍、6人 1.4倍、7人 1.6倍、8人 1.8倍（四捨五入。1体の出現は6人まで1体のまま）
    巣・アンカー・輸送船・降下ポッド・卵などの位置が決まった物と大型ボスは増えません
    敵の数を増やさない場合は ini の [Mission] ExtraEnemies=0（部屋の全員が同じ設定にしてください）
  - スクリプトが1体ずつ置く敵は、7人以上でも複製しません
・ミッション対応をまるごと切るときは ini の [Mission] Extend=0（その場合、5人以上でミッションに行かないでください）

■ 開発・動作確認用の機能（普段は使いません）
・偽メンバー：ini の [RoomScreen] で DummyMembers=1 にすると、部屋画面で F6 が偽メンバーの追加、F7 が削除になります。
  先頭のメンバーの複製が部屋のメンバー一覧に増えるので、隊員欄の表示やページ切り替えだけでなく、
  ボイスチャットの「話している人」の表示など、メンバーを読む表示をまとめて1人で試せます。
  自分のPCの中だけの話で、通信には何も流しません。普段は DummyMembers=0 にしてください。
・ゴースト隊員：ini の [Test] で GhostPlayers=4 のようにすると、オンラインの自分の部屋で1人でミッションを始めたとき、
  自分のコピーが指定した数だけ追加のプレイヤーとして出ます（誰も操作しません。通信には何も流しません）。
  5人以上のミッションを1人で試すためのものです。普段は GhostPlayers=0 にしてください。

■ ログ（不具合があったときに送ってください）
Mods\Plugins\EDF6MultiSlot.log
（部屋の通信や敵の数の詳しい記録も最初から残ります。ログは2MBを超えると古い行から消えていくので、
  放っておいても大きくなりすぎません。詳しい記録が要らないときは ini の NetLog=0 にします）
（1.2.1 以前から使っている ini は NetLog=0 のままです。詳しい記録を残すには NetLog=1 に書き換えるか、ini を消して起動してください）

  1.5.2 から、誰のログなのかがログの中で分かるようになりました。
  ・起動してサインインすると 1回だけ  WHOAMI this log is "（Steam名）", SteamID （数字）
  ・部屋に入ると、メンバーの名前・兵科・アーマーの一覧  ROOM members (6): 0 （名前） Ranger 2014, ...
  ・ゲームを普通に閉じると最後に  SHUTDOWN the game exited
    → この行が無いままログが終わっていたら、そのゲームは「落ちた・強制終了された」ということです。
      次の起動時に PREVIOUS RUN ended without a shutdown line: ... と書きます
  ・部屋の人数の認識がズレたとき  ROOM MISMATCH: n user slots are taken but the room list has m members
    → 「複数人が同時に部屋から落ちる」ときは必ずこれが直前に出ます。出ていたらログを送ってください
  いずれも読むだけで、ゲームには何も書き込みません。

■ 一時的に無効にする
Mods\Plugins\EDF6MultiSlot.ini の Enabled=1 を Enabled=0 にしてゲームを起動
（ゲームには何も書き換えを入れず、Mods\UI\LYT_MAINFRAME.SGO も消します）

■ 削除
1. Mods\Plugins\EDF6MultiSlot.ini を Enabled=0 にして一度ゲームを起動（このMODが書いた Mods\UI\LYT_MAINFRAME.SGO が消えます）
2. Mods\Plugins\EDF6MultiSlot.dll と Mods\Plugins\EDF6MultiSlot.ini を削除
（1 を飛ばして LYT_MAINFRAME.SGO が残っても、表示欄が空のままなので見た目は変わりません）
（EDFModLoaderごと消す場合は、ほかのMODが使っていないことを確認してから winmm.dll も削除）
