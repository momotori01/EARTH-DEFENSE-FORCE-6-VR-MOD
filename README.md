# EARTH DEFENSE FORCE 6 VR MOD

VR mod for EARTH DEFENSE FORCE 6.

## Download

Download the latest version from the Releases section.

## Installation

Extract all files from the ZIP into the EARTH DEFENSE FORCE 6 game folder.

Example:

C:\Program Files (x86)\Steam\steamapps\common\EARTH DEFENSE FORCE 6

## Requirements

- EARTH DEFENSE FORCE 6 (Steam)
- SteamVR / OpenXR compatible VR headset
