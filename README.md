# EARTH DEFENSE FORCE 6 VR MOD

VR mod for the Steam version of EARTH DEFENSE FORCE 6.

## Download

Download the latest mod ZIP from [Releases](https://github.com/momotori01/EARTH-DEFENSE-FORCE-6-VR-MOD/releases).

Download the EDF6VR ZIP under **Assets**, not the automatically generated source code archives.

## Features

- Native stereo rendering.
- Room-scale 6DoF tracking.
- One-handed and two-handed weapon aiming.
- Support for all four soldier classes and vehicles.
- D-pad input through a hand-at-temple gesture.
- In-game weapon position and rotation adjustment.
- Desktop mirror for recording and streaming.

## Installation

Extract all files from the ZIP into the EARTH DEFENSE FORCE 6 game folder, alongside `EDF6.exe`.

Example:

   \Steam\steamapps\common\EARTH DEFENSE FORCE 6

Run `VR_Play.bat` and answer the prompt:

- **Y** — Enable VR and launch the game.
- **N** — Disable VR and launch the game.

Close the game before switching modes.

Read the included `README_EDF6VR.txt` for detailed setup instructions, controls, gestures, and weapon adjustment.

## Requirements

- EARTH DEFENSE FORCE 6 (Steam).
- An OpenXR-compatible VR headset and motion controllers.
- A working OpenXR runtime, such as SteamVR or VDXR.

Tested with Bigscreen Beyond 2, SteamVR, and Index controllers.

Quest controller bindings are included, but Quest and VDXR compatibility has not yet been verified on physical hardware.
